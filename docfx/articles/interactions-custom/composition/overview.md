# Composition

Composition animation catalogs and reusable effects are shipped by `Xaml.Behaviors.Animations`. The package can be used directly without Interactivity. `OrbitEffectBehavior`, `ParallaxBehavior`, and `TiltEffectBehavior` remain in `Xaml.Behaviors.Interactions.Custom` as pointer and lifecycle adapters over the reusable animation APIs.

See the [standalone animations guide](../../animations/index.md) for installation, the API inventory, and direct-use examples.
